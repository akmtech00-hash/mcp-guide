# Recommended tools

## Core development tools

- PHP 8.2+
- Composer
- Git
- Docker
- VS Code or another editor with PHP support

## Later project tools

- Laravel 12.x for framework examples
- Pest or PHPUnit for tests
- PHPStan for static analysis
- Laravel Pint for formatting

## Why these are recommended

They align with the current PHP and Laravel ecosystem and keep the repo practical without relying on unverified SDK assumptions.
